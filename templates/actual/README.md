# Actual

Selbst gehosteter Server für [Actual Budget](https://actualbudget.org/), eine datenschutzfreundliche Haushaltsbuch-App.

## Variablen

| Variable         | Standard  | Bedeutung                     |
|------------------|-----------|-------------------------------|
| `ACTUAL_VERSION` | `latest`  | Image-Tag                     |
| `ACTUAL_PORT`    | `5006`    | Port auf dem Host             |
| `ACTUAL_DATA`    | `./data`  | Datenverzeichnis auf dem Host |

## Aufruf

Nach dem Start erreichbar unter `http://<host>:5006`.
